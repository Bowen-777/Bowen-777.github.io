CAMEL: Cluster Attention Multi-Stage Enhanced Learning for LLaDA

July 2025 – November 2025

Built on LLaDA, a masked diffusion language model, to investigate more efficient inference strategies.

Category
coursework
Status
completed
GitHub ↗

Approach

  • Proposed a cluster-based sparse attention mechanism to improve inference efficiency.
  • Proposed a two-stage inference framework for diffusion language models.

Results

  • Achieved comparable generation quality with improved inference efficiency, with greater speedups on longer sequences.
